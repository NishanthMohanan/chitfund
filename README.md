ChitFund is a local digital chit book built for a single organizer to manage chit funds right from their laptop. Developed using NestJS, Prisma, React, and Tailwind, it handles the end-to-end lifecycle of chit operations while enforcing strict financial integrity. By storing all monetary values in exact paise and logging every action in an append-only audit history, the system eliminates rounding errors and provides a fully traceable ledger for effortless corrections.
